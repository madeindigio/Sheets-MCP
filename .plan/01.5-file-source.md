# Phase 0.5: File Source Resolution

## Goal
Implement a unified `FileSource` that resolves both local paths and URLs into a cached local path. Every tool uses this instead of raw file paths.

## `src/file_source.rs`

### The `FileSource` Enum

```rust
/// Either a local file path or a remote URL
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(untagged)]
pub enum FileSource {
    Url { url: String },
    Path { file_path: String },
}

impl FileSource {
    /// Resolve to a local path on disk.
    /// - If `file_path`: returns it directly (no copy)
    /// - If `url`: downloads, caches in TMPDIR, returns cached path
    pub async fn resolve(&self) -> Result<PathBuf, SheetsError>;

    /// Get the write target path.
    /// - If `file_path` and no output_path provided: write back to same file
    /// - If `url` or output_path provided: write to output_path
    /// - If `url` and no output_path: error (can't write back to URL)
    pub fn write_target(&self, output_path: Option<&str>) -> Result<PathBuf, SheetsError>;
}
```

### URL Download + Cache

```rust
use std::path::PathBuf;
use std::collections::hash_map::DefaultHasher;
use std::hash::{Hash, Hasher};

/// Cache directory: $TMPDIR/sheets_mcp/
fn cache_dir() -> PathBuf {
    std::env::temp_dir().join("sheets_mcp")
}

/// Cache key: SHA256 or hash of URL → reproducible filename
fn cache_path(url: &str) -> PathBuf {
    let mut hasher = DefaultHasher::new();
    url.hash(&mut hasher);
    let hash = hasher.finish();
    // Preserve extension for calamine/umya to detect format
    let ext = std::path::Path::new(url)
        .extension()
        .and_then(|e| e.to_str())
        .unwrap_or("xlsx");
    cache_dir().join(format!("{:x}.{}", hash, ext))
}

async fn download(url: &str) -> Result<PathBuf, SheetsError> {
    let path = cache_path(url);

    // If already cached, skip download
    if path.exists() {
        tracing::info!("Using cached: {} → {:?}", url, path);
        return Ok(path);
    }

    // Ensure cache dir exists
    std::fs::create_dir_all(cache_dir())?;

    // Download
    let response = reqwest::get(url).await?.error_for_status()?;
    let bytes = response.bytes().await?;
    std::fs::write(&path, &bytes)?;

    tracing::info!("Downloaded {} → {:?} ({} bytes)", url, path, bytes.len());
    Ok(path)
}
```

### Tool Input Pattern

Every tool accepts a file source via `#[serde(flatten)]`:

```rust
#[derive(Debug, Deserialize)]
pub struct ReadStructureArgs {
    #[serde(flatten)]
    pub source: FileSource,     // { file_path: "..." } OR { url: "..." }
    #[serde(default = "default_first_n_rows")]
    pub first_n_rows: u32,
}

#[derive(Debug, Deserialize)]
pub struct UpdateCellArgs {
    #[serde(flatten)]
    pub source: FileSource,
    pub sheet_name: String,
    pub coordinate: String,
    pub value: String,
    pub value_type: String,
    /// Required when source is a URL. Optional when source is a local path.
    pub output_path: Option<String>,
}
```

### Write Tool Logic

```rust
pub fn update_cell(
    source: &FileSource,
    output_path: Option<&str>,
    sheet_name: &str,
    update: CellUpdate,
) -> Result<UpdateResult, SheetsError> {
    // Resolve the input path
    let input_path = source.resolve_sync()?;  // use resolve() for async (URL case)

    // Determine the output path
    let output_path = match source {
        FileSource::Path { file_path } => {
            PathBuf::from(output_path.unwrap_or(file_path))
        }
        FileSource::Url { .. } => {
            match output_path {
                Some(p) => PathBuf::from(p),
                None => return Err(SheetsError::MissingOutputPath),
            }
        }
    };

    // Read → modify → write (as before)
    // ...
}
```

### Why `reqwest`?

- Mature async HTTP client, works with Tokio
- `rustls-tls` feature avoids linking OpenSSL (smaller binary, no system dep)
- Only used when `url` input is provided (local path users pay zero cost)

## Acceptance Criteria
- [ ] `FileSource::Path` resolves to the given path directly
- [ ] `FileSource::Url` downloads and caches in `$TMPDIR/sheets_mcp/`
- [ ] Repeat URL reads use cache (no re-download)
- [ ] Write tools error when source is URL and no output_path provided
- [ ] Write tools use output_path when provided, even for local sources
- [ ] Cache directory auto-created on first use
